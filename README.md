The World Gazette is a one-image broadsheet front page that sums up Wednesday 25 November 2026: Ukraine's drone strikes at sea lead the page, followed by the market slide, the Gaza strike, the first Pakistani astronaut reaching Tiangong, and the Houthi attack on Riyadh's tallest tower, with the rest of the day in a small also-today strip. The picture is drawn entirely in code with a tiny built-in pixel font and a hand-written PNG encoder, using only the Node standard library, so every render is byte-identical.

## Run it

```sh
node render.mjs
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
